# Python - Classes and Object Model

This project marks the introduction to Object-Oriented Programming (OOP) in Python. It focuses on exploring the Python object model, defining custom classes, instantiating objects, understanding properties, and implementing essential special methods.

## Requirements
- All files are interpreted and evaluated on Ubuntu 20.04 LTS using `python3` (version 3.8.x)
- Every Python script is executable and ends with a newline character
- Source code is strictly PEP8 compliant (`pycodestyle` 2.7.x)
- Documented strings are provided for all modules, classes, and methods

## Tasks
- **0. Exploring Objects:** Practical conceptual quiz exploring classes, instances, object types, and memory identity.
- **1. My First Square:** Introduction of an empty `Square` class defining a square template.
