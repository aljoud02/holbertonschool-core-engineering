# Python - Inheritance and Polymorphism

This directory contains projects focused on object-oriented programming concepts such as class inheritance, method overriding, polymorphism, and class relationships using `isinstance` and `issubclass`.

## Requirements
- All files are evaluated on Ubuntu 20.04 LTS using Python 3.8
- Code style complies strictly with `pycodestyle` (version 2.7.x)
- Documentation strings are provided without using prohibited keywords in comments

## Tasks
- **0. Introduction to Inheritance and Polymorphism:** Demonstration of basic class inheritance and polymorphic behavior.
- **1. Base Geometry:** Creation of a foundational class `BaseGeometry` with explicit integer validation.
- **2. Rectangle:** Implementation of a `Rectangle` subclass with private dimensions.
- **3. Full Rectangle:** Extended `Rectangle` including area computation and string format.
- **4. Square #1:** Implementation of a specialized `Square` subclass inheriting from Rectangle layout.
- **5. Square #2:** Extended `Square` including individual description overrides.
